That is perfection
===

Write a program to determine whether a number _N_ is equal to the sum of its proper positive divisors in TypeScript and Node.

Input format
---

- first line T, number of cases
- first line N


Print `'Yes'` if _N_ is equal to the sum of its proper positive divisors, else print `'No'`.

Constraints
---

- 1 <= T <= 100
- 1 <= N <= 10^9
 
Limits
---

- time limit: 1.0 secs for each input file
- memory limit 256MB
- source limit: 1024KB
