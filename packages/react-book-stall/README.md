Book stall
===

Write a React program to execute the next operations:

- Given a `title` and `author`, _add_ a book with an `id`
- Given a `book.id`, you can _edit_ the book
- If the `editingId` status is true, _update_ the `title` and the `author` of the book, without modifying the `id`.
- Given a `book.id` you can _delete_ the book
